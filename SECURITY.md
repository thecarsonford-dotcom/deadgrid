# Security policy

## Supported version

Security fixes are made on the latest `main` branch. DEADGRID is pre-alpha and does not currently maintain older release branches.

## Reporting a vulnerability

Please do not open a public Issue for an undisclosed vulnerability. Use GitHub's **Security → Report a vulnerability** flow on the repository. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.

If private vulnerability reporting is temporarily unavailable, contact the maintainer privately using the contact method on the repository owner's GitHub profile. Do not include secrets or personal data in a public channel.

You can normally expect an acknowledgement within seven days. No bug bounty is currently offered.
