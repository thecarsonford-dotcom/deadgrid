# Project governance

DEADGRID is an open-source community project with a maintainer-led model. The goal is to welcome meaningful improvements while preserving a coherent game and the local-model development experiment.

## Roles

### Contributors

Anyone may report bugs, join Discussions, suggest a direction, or submit a pull request. A contribution does not need to be large, and human-only work is welcome.

### Maintainers

Maintainers review contributions, organize releases, manage the repository, and make final decisions about the official project. The current repository owner, `@thecarsonford-dotcom`, is the initial maintainer.

Maintainers may invite established contributors to help review or maintain parts of the project as the community grows. Access is based on sustained constructive participation, sound judgment, and respect for the project policies—not on contribution count alone.

## How decisions are made

- Small fixes and improvements are decided through pull-request review.
- Significant gameplay, architecture, art-direction, dependency, licensing, or policy changes should begin as a GitHub Discussion or proposal issue.
- Maintainers seek community input and explain consequential decisions, but consensus is not required for every change.
- Security reports follow `SECURITY.md` and may be handled privately until a fix is available.

## What enters the official project

A fork can change anything permitted by its licenses. Inclusion in the official DEADGRID repository is a separate decision. Contributions must be maintainable, compatible with the project direction, properly licensed, and compliant with the Code of Conduct and local-model contribution policy.

Contributors retain copyright in their original contributions and license those contributions to the project and its users under Apache-2.0. Third-party material retains its own license.

## Changing this governance

Governance will evolve as the contributor community develops. Material changes will be documented publicly and should be discussed before adoption.
